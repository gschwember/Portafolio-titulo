# Issue tracker: GitHub

Los issues y especificaciones viven en GitHub Issues del repositorio
`gschwember/Portafolio-titulo`.

Usar `gh` para crear, consultar, comentar, etiquetar y cerrar issues.
Cuando una skill indique “publish to the issue tracker”, crear un GitHub Issue.
Cuando solicite un ticket, obtenerlo mediante `gh issue view <number> --comments`.

Los pull requests externos no se tratarán como solicitudes dentro del flujo
de triage, salvo que esta configuración cambie explícitamente.
