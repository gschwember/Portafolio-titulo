# Domain Docs

Antes de trabajar en el proyecto, consultar:

- `CONTEXT.md`, cuando exista.
- Las decisiones relevantes dentro de `docs/adr/`.

El proyecto usa un único contexto de dominio. Los documentos de dominio
se crearán cuando `domain-modeling`, `grill-with-docs` o una decisión real
justifiquen su existencia.

Usar consistentemente el vocabulario definido en `CONTEXT.md`.
Si una propuesta contradice una ADR, señalar el conflicto expresamente.
